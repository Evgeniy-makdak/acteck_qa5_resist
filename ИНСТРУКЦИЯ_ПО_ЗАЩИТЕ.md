# Инструкция по защите советника Acteck QA5

## Как это работает

В исходный код советника добавлена **лицензионная защита**, которая привязывает .ex5 файл к конкретному номеру торгового счёта (и опционально — к серверу брокера).

**Принцип:** вы компилируете .ex5 файл **для каждого клиента отдельно**, указав перед компиляцией номер его счёта. Клиент получает готовый .ex5, который работает **только на его счёте**.

---

## Процесс передачи клиенту

### Шаг 1. Получите данные от клиента
Попросите клиента сообщить:
1. **Номер торгового счёта** (Account Number) — обязательное поле
2. **Имя сервера** (Server Name) — опционально, для дополнительной защиты

Клиент может найти эти данные в терминале MT5:
- Файл → Открыть счёт → вкладка "Управление счетами" → колонка "Счёт" и "Сервер"
- Или в окне "Терминал" → вкладка "Торговля" → навести на баланс → всплывёт номер счёта

### Шаг 2. Откройте файл Acteck.mq5
Откройте файл `MQL5/Experts/Acteck/Acteck.mq5` в MetaEditor.

### Шаг 3. Укажите данные клиента
Найдите в начале файла блок:

```cpp
// >>>>>>>>>>> ЗАПОЛНИТЕ ЭТИ ДВЕ СТРОКИ ПЕРЕД КОМПИЛЯЦИЕЙ <<<<<<<<<<<
// #define LICENSE_ACCOUNT  0
// #define LICENSE_SERVER   ""
// >>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
```

Раскомментируйте строки и укажите данные клиента. Например, для счёта `12345678` на сервере `ICMarkets-Demo01`:

```cpp
#define LICENSE_ACCOUNT  12345678
#define LICENSE_SERVER   "ICMarkets-Demo01"
```

> **Важно:** Если указать `LICENSE_SERVER = ""` (пустая строка), то проверка сервера выполняться не будет — защита будет только по номеру счёта.

### Шаг 4. Скомпилируйте .ex5 файл
В MetaEditor нажмите **F7** (Компилировать). Будет создан файл `Acteck.ex5` в папке `MQL5/Experts/`.

### Шаг 5. Передайте клиенту
Клиенту нужно передать **только**:
1. `Acteck.ex5` — в папку `MQL5/Experts/` терминала MT5
2. `forex.set` — в папку `MQL5/Files/Acteck/` терминала MT5

Исходный код (`Acteck.mq5`) клиенту **не передаётся**.

---

## Что произойдёт при запуске

### Если счёт совпадает:
- Советник запустится нормально
- В журнале появится сообщение: `Acteck QA5: Лицензия подтверждена. Счёт #12345678, сервер: ICMarkets-Demo01`

### Если счёт НЕ совпадает:
- Советник **не запустится** (OnInit вернёт INIT_FAILED)
- На графике появится красное сообщение об ошибке лицензии
- В журнале будет подробное сообщение с номером текущего счёта и сервера

---

## Режим разработки (без защиты)

Если оставить макросы закомментированными (как в исходном файле):

```cpp
// #define LICENSE_ACCOUNT  0
// #define LICENSE_SERVER   ""
```

то защита **отключена**, и советник будет работать на любом счёте. Это удобно для тестирования.

---

## Ограничения защиты

⚠️ **Важно понимать:** защита через `AccountInfoInteger(ACCOUNT_LOGIN)` и `AccountInfoString(ACCOUNT_SERVER)` — это **программная защита уровня MQL5**. Она обеспечивает базовый уровень защиты от случайного распространения, но:

1. **Не является криптостойкой** — опытный программист на MQL5 может дизассемблировать .ex5 и обойти проверку
2. **Не защищает от передачи файла другому человеку** — если клиент передаст .ex5 другому, тот не сможет его использовать (если у него другой счёт), но может попытаться взломать
3. **Не привязана к железу** — привязка к компьютеру в MQL5 технически сложнее и менее надёжна

Для коммерческого использования рекомендуется дополнительно:
- Использовать обфускацию кода
- Добавить несколько проверок в разных местах кода
- Рассмотреть сторонние сервисы защиты MQL5

## Технические детали

Функция проверки лицензии — `CheckLicense()`:
- Вызывается в самом начале `OnInit()`
- Получает текущий номер счёта через `AccountInfoInteger(ACCOUNT_LOGIN)`
- Получает имя сервера через `AccountInfoString(ACCOUNT_SERVER)`
- Сравнивает с заданными при компиляции значениями
- При несовпадении выводит сообщение на график и возвращает `false`
